# best web scrapping github and huggingface repos

Aqui estão os melhores repositórios de web scraping tanto no GitHub quanto no Hugging Face, Thiago:

## Top GitHub — Web Scraping

**[Firecrawl](https://github.com/firecrawl/firecrawl)** é disparado o repositório mais popular no momento, com impressionantes **114.225 stars** . É uma API completa voltada para IA que faz scraping, busca e interação com a web, convertendo páginas HTML em Markdown — perfeito para alimentar pipelines de LLMs e RAG . Foi criado em abril de 2024 e já tem mais de 7.200 forks, o que demonstra adoção muito rápida.

**[Scrapy](https://github.com/scrapy/scrapy)** é o framework Python mais consolidado da área, com **61.500+ stars** e mais de 15 anos de maturidade . É a escolha padrão para crawling em larga escala, com arquitetura baseada em spiders, pipelines de itens e suporte a middlewares — extremamente útil para automação jurídica e extração de dados de tribunais como PJe ou e-Proc .

**[Scrapling](https://github.com/D4Vinci/Scrapling)** é um projeto mais recente (**41.500+ stars**) com foco em scraping adaptativo que lida com sites dinâmicos, anti-bot e stealth . Integra Playwright e suporte a XPath/CSS selectors, além de já ter um servidor MCP nativo — excelente integração com agentes de IA .

**[Crawlee (Apify)](https://github.com/apify/crawlee)** é a solução em TypeScript/Node.js mais robusta, com **23.000+ stars**, suportando Puppeteer, Playwright, Cheerio e rotação de proxies . É ideal para automação de navegadores headless em escala, com suporte a extração de PDFs e imagens .

**[Maxun](https://github.com/getmaxun/maxun)** é uma plataforma **no-code open-source** com **15.500+ stars** para criar scrapers visuais e transformar sites em APIs estruturadas sem escrever código . Muito útil se você quiser automatizar extração de dados sem depender de um desenvolvedor .

**[Obscura](https://github.com/h4ckf0r0day/obscura)** é um projeto recente de abril de 2026 escrito em **Rust**, posicionado como navegador headless leve para agentes de IA — já tem quase **9.600 stars** em poucas semanas, indicando forte adoção na comunidade .

## Hugging Face — Web Scraping

No Hugging Face, o espaço **[DataPrism/GPT-auto-webscraping](https://hf.co/spaces/DataPrism/GPT-auto-webscraping)** é o mais destacado, utilizando GPT para automatizar a geração de scrapers a partir de uma descrição em linguagem natural via Streamlit . É uma demonstração interessante de como LLMs podem simplificar a criação de pipelines de extração.

O espaço **[pvanand/web-scraping](https://hf.co/spaces/pvanand/web-scraping)** e **[nielitropar/webscraping](https://hf.co/spaces/nielitropar/webscraping)** são containers Docker com ferramentas de scraping prontas para uso via API . Para modelos, o **[gustavo-fluz/web-scraping-slm-mmlu-poc](https://hf.co/gustavo-fluz/web-scraping-slm-mmlu-poc)** (criado em abril de 2026) explora o uso de Small Language Models (SLMs) para tarefas de scraping — uma tendência emergente de usar modelos menores e mais eficientes para extração estruturada .
